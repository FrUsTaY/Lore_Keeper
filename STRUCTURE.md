# Структура и иерархия файлов проекта

В данном документе описана структура папок и файлов проекта, а также их основное назначение.

  - `.gitignore` — Указывает файлы и папки, которые Git должен игнорировать.
  - `AUDIT.md` — Файл аудита, вероятно, содержит заметки или логи проверки проекта.
  - `LoreKeeper.spec` — Файл конфигурации PyInstaller для сборки приложения в исполняемый файл (.exe).
  - `README.md` — Главная документация проекта, содержит описание, инструкции по установке и настройке.
  - `STRUCTURE.md` — Этот файл, описывающий структуру и иерархию файлов проекта.
  - `build.py` — Скрипт сборки приложения с помощью PyInstaller, управляет зависимостями и ресурсами.
  - `icon.ico` — Иконка приложения.
  - `main.py` — Главная точка входа в приложение, настраивает окружение и запускает графический интерфейс (GUI).
  - `requirements.txt` — Список Python-зависимостей, необходимых для работы проекта.
  - `update_settings_dialog.patch` — Патч-файл для внесения изменений в диалог настроек (вероятно, оставшийся после разработки).
  - **configs/**
    - `capture_config.json` — Настройки захвата аудио, такие как длительность чанка и порог тишины.
    - `genres.json` — Определяет доступные жанры для генерации историй и их базовые промпты для LLM.
    - `lm_studio_config.json` — Конфигурация подключения к локальной модели через LM Studio.
    - `test_config.json` — Конфигурация, используемая для запуска тестов.
  - **src/**
    - `__init__.py` — Делает директорию src Python-модулем.
    - `audio_capture.py` — Отвечает за запись аудио с системных устройств с использованием WASAPI (PyAudioWPatch).
    - `audio_transcriber.py` — Управляет фоновым процессом транскрибации записанного аудио в текст.
    - `config_manager.py` — Управляет чтением, сохранением и предоставлением доступа к конфигурационным файлам приложения.
    - `context_selector.py` — Выбирает наиболее важные события, если лог становится слишком длинным для контекста LLM.
    - `deduplicator.py` — Очищает лог от повторяющихся событий с помощью алгоритмов нечеткого поиска (Levenshtein).
    - `entity_extractor.py` — Извлекает имена персонажей и локации из текста с использованием spaCy (NER).
    - `event_logger.py` — Ведет и сохраняет JSON-лог событий (распознанных реплик) для текущей сессии.
    - `generate.py` — Скрипт командной строки для ручного запуска генерации истории из существующего лога.
    - `groq_client.py` — Клиент для взаимодействия с облачным API Groq (LLM и распознавание речи Whisper).
    - `lm_studio_client.py` — Клиент для взаимодействия с локальным сервером LM Studio (генерация текста через LLM).
    - `local_transcriber.py` — Управляет локальным распознаванием речи с помощью faster-whisper (CPU/GPU).
    - `main_console.py` — Консольная точка входа в приложение (без графического интерфейса), для отладки или запуска в фоне.
    - `prompt_builder.py` — Формирует итоговый системный промпт для LLM, объединяя жанр, контекст и правила.
    - `screen_capture.py` — Модуль для создания скриншотов экрана (находится в разработке/используется как запасной).
    - `session_manager.py` — Управляет текущей сессией: создание новых логов, загрузка существующих.
    - `story_generator.py` — Координирует весь процесс превращения лога событий в художественный рассказ (очистка, контекст, запрос к LLM).
    - `time_segmenter.py` — Анализирует время между событиями и вставляет маркеры смены сцен, если прошло много времени.
    - `trigger_manager.py` — Управляет основным циклом приложения: захватом аудио и передачей на транскрибацию.
    - **utils/**
      - `__init__.py` — Делает директорию utils Python-модулем.
      - `gpu_tester.py` — Вспомогательный скрипт для безопасного тестирования инициализации CUDA/GPU в изолированном процессе.
      - `path_utils.py` — Предоставляет функции для корректного разрешения путей к файлам (работает как в исходниках, так и в собранном .exe).
    - **gui/**
      - `__init__.py` — Делает директорию gui Python-модулем.
      - `main_window.py` — Главное окно графического интерфейса приложения (PySide6).
      - `session_editor_dialog.py` — Диалоговое окно для ручного редактирования лога сессии перед генерацией истории.
      - `workers.py` — Содержит QThread-воркеры для выполнения долгих задач (запись, генерация, скачивание CUDA) в фоне, не блокируя интерфейс.
  - **tests/**
    - `test_audio_capture.py` — Тесты для модуля захвата аудио (проверка моков).
    - `test_audio_volume.py` — Тесты для проверки порога громкости (noise gate) при записи аудио.
    - `test_core.py` — Базовые тесты для проверки корректности импортов модулей приложения.
    - `test_entity_extractor.py` — Тесты для проверки правильности извлечения сущностей (NER).
    - `test_gpu_crash.py` — Скрипт для тестирования падений при работе с GPU (отладка конфликтов DLL).
    - `test_groq.py` — Тестовый скрипт для проверки работоспособности ключа API Groq.
    - `test_gui.py` — Проверка успешной инициализации и импортов главного окна GUI.
    - `test_main.py` — Тест успешного импорта TriggerManager (основного компонента).
    - `test_phase4.py` — Тесты для проверки импортов модулей четвертой фазы (генерации истории).
    - `test_prompt_builder.py` — Тесты для проверки корректности формирования промптов.
    - `test_session_manager.py` — Тесты для управления сессиями (добавление событий).
    - `test_time_segmenter.py` — Тесты для проверки логики разделения сессий по времени.
