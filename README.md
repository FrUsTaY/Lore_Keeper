# Нарративный Архивариус (Lore Keeper)

Десктопное приложение для Windows, которое автоматически ведёт «дневник приключений» по вашей игре. Оно записывает аудио игры (реплики персонажей) с помощью Whisper API, а затем превращает этот сухой лог в художественный рассказ от первого лица с помощью локальной LLM.

## Возможности
- Фоновый перехват системного аудио и транскрибация речи в текст.
- Умный фильтр тишины (записывает только когда персонажи говорят).
- Интеграция с локальной нейросетью через LM Studio для генерации историй.
- Дедупликация и автоматическое извлечение ключевых персонажей (NER).
- Современный GUI с поддержкой системного трея.

## Требования
- Python 3.11.5
- Установленные зависимости из `requirements.txt`
- Установленная и запущенная программа **LM Studio** (локально) ИЛИ токен для доступа к **Groq API** (для слабых ПК).

## Настройка распознавания аудио (Voice-to-Text)

Приложение предлагает три режима распознавания речи персонажей. Вы можете выбрать их в меню **Настройки**:

1. **Groq API (Облако - Рекомендуется):** Использует сверхбыстрые сервера Groq (модель Whisper Large V3). Не нагружает ваш ПК. Требует API ключ.
2. **Local Whisper (Полностью автономно):** Использует встроенную библиотеку `faster-whisper`. Модель скачивается автоматически при первой записи и работает на вашем процессоре или видеокарте без интернета. Вы можете выбрать размер модели (от `tiny` до `medium`).
3. **LM Studio (Кастомный URL):** Если у вас запущен локальный сервер (например, LocalAI или LM Studio с поддержкой аудио), вы можете направить запросы туда.

### Как пользоваться чисто локально (Оффлайн на мощном ПК)
Если вы хотите 100% автономности без использования облачных API:
1. Зайдите в **Настройки**.
2. В блоке "Провайдер LLM" выберите **LM Studio**.
3. В блоке "Распознавание Аудио" выберите **Local Whisper (CPU/GPU)** и укажите размер модели (например, `base` или `small`).
4. **Как это работает:** Никаких дополнительных программ скачивать не нужно! При первом запуске записи программа автоматически скачает выбранную модель (например, `base` весит ~140 МБ) с серверов Hugging Face в скрытую папку кэша на вашем диске. Во время игры (нагружая CPU/GPU в фоновом режиме). Когда вы закончите играть и нажмете "Сгенерировать историю", программа обратится к вашему запущенному серверу LM Studio, чтобы превратить текст в литературный рассказ. Оба процесса происходят строго на вашем ПК!

## Настройка LLM (Генерация истории)

(Выберите провайдера для финальной обработки текста)

### Вариант 1: LM Studio (Для мощных ПК)
1. Скачайте [LM Studio](https://lmstudio.ai/).
2. Загрузите предпочитаемую модель (Qwen 1.5B Instruct - отличный выбор для слабых ПК).
3. Перейдите во вкладку "Local Server".
4. Убедитесь, что сервер запущен на порту `1234`.
5. Включите опцию CORS (если необходимо).

### Вариант 2: Groq API (Для аудио-распознавания и быстрой генерации)
1. Зарегистрируйтесь на сайте [Groq](https://console.groq.com/).
2. Создайте API ключ в разделе API Keys.
3. При запуске приложения зайдите в настройки (⚙ Настройки).
4. Выберите "Провайдер LLM: Groq", вставьте скопированный токен.
5. **Важно:** Запись аудио (Whisper API) работает только если указан ключ Groq API.

## Установка и запуск

1. Склонируйте репозиторий.
2. Рекомендуется создать независимое окружение. Создайте окружение (внутри папки проекта):
   ```bash
   python -m venv venv
   ```
3. Активируйте его:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   pip install "https://github.com/explosion/spacy-models/releases/download/ru_core_news_sm-3.7.0/ru_core_news_sm-3.7.0-py3-none-any.whl"
   ```
5. Запустите приложение:
   ```bash
   python main.py
   ```
