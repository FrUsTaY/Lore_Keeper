# Нарративный Архивариус (Lore Keeper)

Десктопное приложение для Windows, которое автоматически ведёт «дневник приключений» по вашей игре. Оно делает скриншоты экрана, распознаёт текстовые подписи (названия квестов, имена NPC, локации, ключевые диалоги), а затем превращает этот сухой лог в художественный рассказ от первого лица с помощью локальной LLM.

## Возможности
- Фоновый захват экрана и распознавание текста без снижения FPS.
- Умная система детектирования изменений (записывает только новую информацию).
- Интеграция с локальной нейросетью через LM Studio для генерации историй.
- Дедупликация и автоматическое извлечение ключевых персонажей (NER).
- Современный GUI с поддержкой системного трея.

## Требования
- Python 3.11.5
- Установленные зависимости из `requirements.txt`
- Установленная и запущенная программа **LM Studio** (локально) ИЛИ токен для доступа к **Hugging Face Inference API** (для слабых ПК).
- Установленный **Tesseract OCR** (для распознавания текста).

## Настройка Tesseract OCR (Обязательно)
1. Скачайте установщик Tesseract OCR для Windows (например, от [UB-Mannheim](https://github.com/UB-Mannheim/tesseract/wiki)).
2. При установке **обязательно** выберите русский язык (Russian language data).
3. По умолчанию программа будет искать Tesseract по пути: `C:\Program Files\Tesseract-OCR\tesseract.exe`. Вы можете изменить путь в настройках приложения.

## Настройка LLM (на выбор)

### Вариант 1: LM Studio (Для мощных ПК)
1. Скачайте [LM Studio](https://lmstudio.ai/).
2. Загрузите предпочитаемую модель (Qwen 1.5B Instruct - отличный выбор для слабых ПК).
3. Перейдите во вкладку "Local Server".
4. Убедитесь, что сервер запущен на порту `1234`.
5. Включите опцию CORS (если необходимо).

### Вариант 2: Hugging Face (Для слабых ПК без локальной LLM)
1. Зарегистрируйтесь на сайте [Hugging Face](https://huggingface.co/).
2. Перейдите в настройки (Settings) -> Access Tokens и создайте новый токен (Read/Write).
3. При запуске нашего приложения зайдите в настройки (⚙ Настройки).
4. Выберите "Провайдер LLM: Hugging Face", вставьте скопированный токен и укажите модель (по умолчанию вписана `mistralai/Mistral-7B-Instruct-v0.2`).

## Установка и запуск

1. Склонируйте репозиторий.
2. Рекомендуется создать независимое окружение. Создайте окружение (внутри папки проекта):
   ```bash
   python -m venv venv
   ```
3. Активируйте его:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   pip install "https://github.com/explosion/spacy-models/releases/download/ru_core_news_sm-3.7.0/ru_core_news_sm-3.7.0-py3-none-any.whl"
   ```
5. Запустите приложение:
   ```bash
   python main.py
   ```
