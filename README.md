# Нарративный Архивариус (Lore Keeper)

Десктопное приложение для Windows, которое автоматически ведёт «дневник приключений» по вашей игре. Оно записывает аудио игры (реплики персонажей) с помощью Whisper, а затем превращает этот сухой лог в художественный рассказ от первого лица с помощью локальной или облачной LLM.

## Возможности
- Фоновый перехват системного аудио игры с помощью WASAPI (PyAudioWPatch).
- Транскрибация речи в текст (локально на вашем ПК или через облачное API).
- Умный фильтр тишины на основе децибел (записывает только когда персонажи говорят).
- Интеграция с локальной нейросетью через LM Studio или облачной через Groq для генерации историй.
- Дедупликация и автоматическое извлечение ключевых персонажей (NER) с помощью spaCy.
- Умная разбивка сессий с определением разрывов во времени.
- Современный GUI с поддержкой системного трея и глобальными горячими клавишами.
- **Новое:** Автоматический загрузчик библиотек CUDA (cuBLAS и cuDNN) для мгновенного включения ускорения видеокарт NVIDIA RTX для локального распознавания речи.

## Требования
- Windows 10/11
- Python 3.11.5
- Установленные зависимости из `requirements.txt`

## Настройка распознавания аудио (Voice-to-Text)

Приложение предлагает два режима распознавания речи персонажей. Вы можете выбрать их в меню **Настройки**:

1. **Облачный (Groq API):** Использует сверхбыстрые сервера Groq (модель Whisper Large V3). Не нагружает ваш ПК. Требует API ключ.
2. **Локальный (Встроенный движок):** Использует встроенную библиотеку `faster-whisper`. Модель скачивается автоматически при первой записи и работает на вашем процессоре (CPU) или видеокарте (GPU) без интернета. Вы можете выбрать размер модели (от `small` до `large-v3-turbo`).

### Ускорение на видеокартах NVIDIA (CUDA)
Для режима **Локальный (Встроенный движок)** предусмотрено автоматическое ускорение GPU:
1. Выберите устройство **GPU (CUDA)** или **Авто** в настройках.
2. По умолчанию будет выбрана модель **large-v3-turbo**, обеспечивающая превосходную точность русского языка и высокую скорость генерации.
3. Если на вашем ПК отсутствуют библиотеки CUDA (cuBLAS, cuDNN), приложение автоматически предложит их скачать. Распаковка архива произойдет прозрачно в папку `cuBLAS and cuDNN` внутри директории программы.

## Настройка LLM (Генерация истории)

(Выберите провайдера для финальной обработки текста)

### Вариант 1: LM Studio (Для мощных ПК, оффлайн)
1. Скачайте [LM Studio](https://lmstudio.ai/).
2. Загрузите предпочитаемую модель (Qwen 2.5 или Llama 3).
3. Перейдите во вкладку "Local Server".
4. Убедитесь, что сервер запущен на порту `1234`.
5. Включите опцию CORS (если необходимо).
6. В приложении зайдите в настройки и выберите "Провайдер LLM: LM Studio".

### Вариант 2: Groq API (Быстрая генерация в облаке)
1. Зарегистрируйтесь на сайте [Groq](https://console.groq.com/).
2. Создайте API ключ в разделе API Keys.
3. При запуске приложения зайдите в настройки (⚙ Настройки).
4. Выберите "Провайдер LLM: Groq", вставьте скопированный токен и нажмите "Проверить доступные мне модели".

## Установка и запуск

1. Склонируйте репозиторий.
2. Создайте независимое окружение (внутри папки проекта):
   ```bash
   python -m venv venv
   ```
3. Активируйте его:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   pip install "https://github.com/explosion/spacy-models/releases/download/ru_core_news_sm-3.7.0/ru_core_news_sm-3.7.0-py3-none-any.whl"
   ```
5. Запустите приложение:
   ```bash
   python main.py
   ```
